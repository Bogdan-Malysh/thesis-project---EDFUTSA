> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce reproducible hourly descriptive statistics, annual summaries, and a two-panel daily-load development figure for Germany and Austria from the final modelling datasets.

**Architecture:** `code/03_exploratory_analysis/section_5_1.py` will read only `timestamp_local`, `timestamp_utc`, and `actual_grid_load_mwh`, validate the complete 2020–2025 hourly inputs, and expose pure functions for hourly statistics, annual summaries, and local daily series. Its CLI will write exactly the requested table, annual CSV, PNG, and PDF outputs under `outputs/chapter5/section_5_1/`. The figure will use local calendar dates derived directly from `timestamp_local`, daily means, and a trailing 30-day moving average.

**Tech Stack:** Python 3, pandas, NumPy, Matplotlib, pytest.

## Data Contract

- Input files: `data/processed/modelling_germany_hourly.csv` and `data/processed/modelling_austria_hourly.csv`.
- Read only `timestamp_local`, `timestamp_utc`, and `actual_grid_load_mwh`.
- Require 52,608 rows, finite actual load, unique ordered hourly UTC timestamps, and local years exactly 2020–2025.
- Derive local dates with `pd.Timestamp(value).date()` from the raw `timestamp_local` string; do not convert UTC to local independently.
- Require exactly 2,192 local daily observations per country from 2020-01-01 through 2025-12-31.

## Output Contract

Table 5.1 uses `statistic,Germany,Austria` rows for `Number of observations`, `Mean`, `Standard deviation`, `Minimum`, `First quartile`, `Median`, `Third quartile`, and `Maximum`. Counts are integers; all other displayed values are rounded to two decimals. Standard deviation uses pandas’ sample convention (`ddof=1`) and quartiles use the default linear quantile method.

Annual summary uses columns `country,year,number_of_hourly_observations,mean_hourly_grid_load_mwh,standard_deviation_mwh,minimum_mwh,maximum_mwh,percentage_change_mean`. The first year’s percentage change is blank because no previous year exists; other numeric values are rounded to two decimals.

Figure 5.1 uses daily mean hourly load as a thin light blue line and a darker thicker 30-day trailing moving average with `min_periods=30`. It uses two vertically stacked panels, shared x-axis, separate y-axes, local date limits 2020-01-01 through 2025-12-31, and 300 dpi PNG plus PDF output.
