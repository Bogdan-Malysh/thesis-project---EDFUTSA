# Chapter 5.2 Hourly Demand Patterns Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce Germany and Austria local-hour demand profiles with descriptive statistics and a two-panel mean/interquartile figure from the final modelling datasets.

**Architecture:** `code/03_exploratory_analysis/section_5_2.py` will read only `actual_grid_load_mwh` and the established local `hour` column from each modelling CSV, validate the complete hourly inputs, calculate six statistics for every country-hour pair, and write one 48-row profile CSV. It will render the profile as two vertically arranged panels using the Section 5.1 colours and formatting, without importing or recalculating any Section 5.1 data.

**Tech Stack:** Python 3, pandas, NumPy, Matplotlib, pytest.

---

## File Map

- Create `code/03_exploratory_analysis/section_5_2.py`: loading, validation, hourly aggregation, CSV writer, figure renderer, and CLI.
- Create `code/03_exploratory_analysis/test_section_5_2.py`: input, aggregation, CSV, figure, and immutability tests.
- Create `outputs/chapter5/section_5_2/hourly_demand_profile.csv`.
- Create `outputs/chapter5/section_5_2/figure_5_2_hourly_demand_patterns.png`.
- Create `outputs/chapter5/section_5_2/figure_5_2_hourly_demand_patterns.pdf`.
- Do not modify modelling inputs, Section 5.1 outputs, raw data, or validation files.

## Data Contract

- Inputs: `data/processed/modelling_germany_hourly.csv` and `data/processed/modelling_austria_hourly.csv`.
- Read only `actual_grid_load_mwh` and `hour`; do not derive hour from UTC or use other explanatory variables.
- Require 52,608 rows, finite actual load, and integer local hours 0 through 23.
- Require each country-hour group to contain 2,192 observations, with counts summing to 52,608.
- Use sample standard deviation (`ddof=1`) and pandas’ default linear quartiles, consistent with Section 5.1.

## Output Contract

The CSV columns are `country,hour,number_of_observations,mean_hourly_grid_load_mwh,median_hourly_grid_load_mwh,standard_deviation_mwh,first_quartile_mwh,third_quartile_mwh`. It has exactly 48 rows, sorted by country and hour, with displayed statistics rounded to two decimals and counts retained as integers.

The figure has two vertical panels, Germany above Austria, separate y-axes, x ticks `0,2,...,22`, dark-blue mean lines, light-blue interquartile shading, y-axis label `Hourly grid load [MWh]`, comma-formatted y ticks, a simple shared legend, no main title, 300 dpi PNG, and vector PDF.
