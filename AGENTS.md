# Project Instructions

- Keep the entire project and all data on this laptop.
- Do not create a GitHub repository.
- Do not add a Git remote, push, upload, share, or publish project files.
- Do not initialize Git without explicit user approval.
- Treat every file in `data/raw/` as immutable. Never edit, rename, move, overwrite, clean, or delete a raw file.
- Use ordinary Python `.py` files, not Jupyter notebooks.
- Use classical time-series methods only.
- Do not use machine-learning models, Prophet, or `pmdarima`.
- Do not begin modelling before preprocessing has been validated.
- Use chronological validation and prevent data leakage.
- Analyse Germany and Austria separately.
- Treat official forecasts as external benchmarks, not model inputs.
- Use the project interpreter at `.venv\Scripts\python.exe` for every Python command.
- Do not add files, dependencies, abstractions, or features unless the approved design explicitly requires them.
